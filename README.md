# Crypto Lab

Комплекс лабораторных работ по дисциплине «Защита информации».

## Что внутри

- **BigNum** — собственная реализация арифметики больших чисел
  (сложение, вычитание, умножение, деление по алгоритму Кнута,
  возведение в степень, НОД, НОК).
- **Кузнечик** — блочный шифр по ГОСТ Р 34.12-2015.
- **Стрибог** — хэш-функция по ГОСТ Р 34.11-2012.
- **RSA** — асимметричное шифрование на GMP.

## Структура

- `bignum/` — арифметика больших чисел
- `common/` — общие утилиты (hex, конфиг, энтропия)
- `kuznyechik/` — шифр Кузнечик
- `rsa/` — RSA
- `streebog/` — хэш Стрибог
- `tests/` — тесты и тестовые векторы

## Сборка

Требования:
- GCC
- GMP (`libgmp-dev`)
- cJSON (`libcjson-dev`)
- pthread

```bash
make clean && make
```
## Запуск

```bash
./build/main <mode>
```
Где <mode>:
- bignum — тесты арифметики больших чисел
- kuz — тесты Кузнечика
- streebog — тесты Стрибога
- rsa — тесты RSA
- all — всё сразу

Параметры задаются в config.json
